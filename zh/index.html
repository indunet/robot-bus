开源机器人中间件

让机器人系统
互联互通。

面向机器人应用的轻量级消息框架。基于 ZeroMQ，提供六种 SDK、ROS 2 风格的话题、服务和动作，以及可选的 ROS 2 桥接。

快速开始 查看 GitHub 源码

消息模型

三种消息模式。

基于统一的 Node API，按场景选择发布订阅、请求响应，或带反馈的异步任务。

话题

将传感器读数、状态更新等持续数据分发给多个订阅方。

/robot1/imu

服务

发起一次明确的操作并接收类型化响应，例如切换设备开关。

/set_bool

动作

为长时间运行的任务发送目标、接收进度反馈，并获取结果或取消目标。

/fibonacci
查看系统架构

快速开始

选择你的 SDK。

Rust 控制器、Python 工具和 TypeScript 浏览器应用可以连接同一个 Broker。安装 SDK 后，按对应指南接入。

运行 Python 快速开始示例
Shell
pip install robot-bus
查看 Python 指南
Cargo.toml
[dependencies]
robot-bus = "2.4.3"
查看 Rust 指南
Shell
npm install robot-bus
查看 TypeScript 指南
Shell
sudo apt install ./robot-bus_2.4.3_linux_amd64.deb
查看 C++ 指南
pom.xml
<dependency>
  <groupId>org.indunet</groupId>
  <artifactId>robot-bus</artifactId>
  <version>2.4.3</version>
</dependency>
查看 Java 指南
build.gradle.kts
implementation("org.indunet:robot-bus-android:2.4.3")
查看 Android 指南

内嵌 Web 控制台

看见节点如何协作。

Broker 自带 Web 控制台。用浏览器即可查看消息活动、连接关系和节点状态。

  • 查看消息拓扑

    浏览话题、服务、动作及其连接。

  • 体验坦克模拟器

    用键盘操控，或在地图上点击发送目标。

技术文档

从接入到部署。

部署与排查运行嵌入式 Broker，或建立跨主机连接。 ROS 2 桥接通过可选的进程内桥接接入 Humble 或 Jazzy。 ROS 2 浏览器实验运行从浏览器经 Python 桥接到真实 ROS 2 节点的示例。 性能与 QoS了解队列行为和基准测试方法。 支持矩阵查看支持的平台和已验证的功能。
