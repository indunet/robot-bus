# ROS 2 Bridge performance report

Generated by `just perf-ros2-bridge` (`ros2_bridge_perf`). **Not a CI gate.**

## Environment

- Date: 2026-08-31.
- `/opt/ros/humble` is present on the host, but Docker container `ros2` is **missing** (`docker inspect ros2` failed), so default `just perf-ros2-bridge` (sync into that container) did not run.
- After `source /opt/ros/humble/setup.bash`, `cargo check --release --bin ros2_bridge_perf --features ros2` **failed**: generated topic mappers do not type-check against distro rust IDL (e.g. `visualization_msgs/MenuEntry.command` is `std::string::String` rather than `rosidl_runtime_rs::String`; `command_type` is `u8` rather than `u32`). No `/tmp/ros2_rust_ws` overlay.
- No GitHub Actions Humble/Jazzy job was added (by design).
- The harness now includes Trigger / Fibonacci both directions (KeepLast matches topic benches). Fill numbers when a `ros2` container with a matching rust IDL overlay is available.

## Method

- In-process broker + `Ros2Bridge`; one ROS peer and one bus peer.
- Scenarios: 64-byte `std_msgs/String`; Image default 640×480 rgb8 (`ROS2_BRIDGE_PERF_IMAGE_WIDTH/HEIGHT`); Trigger / Fibonacci both directions.
- Directions: ROS→bus and bus→ROS.
- Goodput: paced ~1s trials, binary search max rate with loss ≤ 1%.
- Latency: separate paced samples (send one, wait, repeat).
- QoS: KeepLast(2048) best_effort (bench only).
