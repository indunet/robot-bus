# ROS 2 Bridge performance report

Generated by `just perf-ros2-bridge` (`ros2_bridge_perf`). **Not a CI gate.** Empty until the harness has been run.

## Environment

- Fill by running `just perf-ros2-bridge` (`ros2` container + rust IDL overlay).

## Method

- In-process broker + `Ros2Bridge`; one ROS peer and one bus peer.
- Scenarios: 64-byte `std_msgs/String`; Image default 640×480 rgb8 (`ROS2_BRIDGE_PERF_IMAGE_WIDTH/HEIGHT`).
- Directions: ROS→bus and bus→ROS.
- Goodput: paced ~1s trials, binary search max rate with loss ≤ 1%.
- Latency: separate paced samples (send one, wait, repeat).
- QoS: KeepLast(2048) best_effort (bench only).
